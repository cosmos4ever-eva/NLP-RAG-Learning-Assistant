## Bad Cases 与迭代

原始课程目录包含 L2 PPTX，但原解析器只扫描 PDF，导致 L2 证据缺席。补齐后 EVAL-001、002、004、005、006、007 从未命中变为命中，覆盖 tokenization、词干/词形、分词歧义、双向匹配、jieba 模式和预处理流程。

加入 PPTX 后，EVAL-012（编辑距离与余弦相似度）曾从命中变为未命中，说明语料补齐会改变 TF-IDF 排名。随后对比较题保留第二资料来源，并为语义锚点展开相邻页；跨概念题由 0/2 提升到 2/2。上下文块按页限额，避免同一张表格页切出的多个块耗尽提示词预算。

仍未覆盖 EVAL-003 与 EVAL-020：前者的归一化问题与后者的 PMI 低频缺陷距离当前语义锚点较远，不能靠继续扩大相邻页窗口解决。后续应优先补充 OCR/结构化标题或查询改写，而不是无限增加提示词长度。

## 复现

### 2026-11-23 接口实测补充

用户环境变量已配置并被读取。首次调用因环境代理发生 TLS EOF；增加 `--direct` 选项后，保留 TLS 证书校验，直连正常到达服务。真实生成请求和 models 检查均返回 HTTP 401，服务提示 token 无效或已过期。尚无成功生成的回答，不能计算三组答案质量。需要更新有效 ECNUgpt API Key 后继续。密钥未写入实验文件。

```powershell
python evaluation/validate_dataset.py
python evaluation/run_experiment.py --output evaluation/private_runs/新建目录
$env:ECNUGPT_API_KEY=[Environment]::GetEnvironmentVariable("ECNUGPT_API_KEY","User")
python evaluation/run_experiment.py --direct --generate --output evaluation/private_runs/新的回答目录
```

目录必须不存在以防覆盖旧证据。private_runs 含课程原文、逐题检索与提示，已加入 gitignore。每轮保存代码、数据、课程文件哈希。生成前先调用 models 接口鉴权；401 时不发起模型回答请求。限流和服务端暂时错误最多重试三次，其他模型错误保留已完成回答并终止，不冒充有效结果。
